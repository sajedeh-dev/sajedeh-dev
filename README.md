### 👩‍💻 About me

Frontend developer with a **Computer Engineering** background .

My work goes beyond implementing screens. I work with real API contracts, application state, authentication flows and product requirements, and turn designs and specs into interfaces that are structured, responsive and maintainable.

**How I work**

- 🧩 **Understand the product, not just the screen.** I think through requirements, data flow, user states and API behavior before I write code.
- 🔁 **Build for change.** I keep component responsibilities clear so features can evolve without extra complexity.
- 🌐 **Treat UI as part of the system.** RTL support, responsiveness, and loading and error states are part of the work, not afterthoughts.
- 🛠️ **Write code I can own.** I prefer code I can explain, debug and extend over code that only works once.
